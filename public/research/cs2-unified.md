# CS2 Unified in the guns preview

The user-selected source is `cs2_unified-2.7.0-mode-sounds-2026-10-07.zip` from the CurseForge instance `The Last War_ Floydian`. Run `npm run mods:fetch-cs2` to install it, or pass a ZIP path / set `CS2_PACK`. Installation copies the original pack files byte for byte into Git-ignored `public/mods/cs2/`, recording the source filename and SHA-256. Keep the authors' original credits and terms. Source commits contain the loader and synthetic tests, not the pack payload. The protected Pages publication encrypts these files with the rest of the application.

The 40 gun entries become 38 firearms and two default CT/T knives; the 10 LR Tactical knives bring the knife total to 12. Default TaCZ's 70 guns remain available, for 108 firearms overall. CS2 weapons use shared TaCZ ammunition. Six CS2 scopes/silencers are supported through the existing attachment UI. Models, icons, animations, language files, sounds and attachment allowlists retain their namespace, including references to shared TaCZ models/data. The pack's experimental AK entry is included.

The ten old `cs2_wt` knives are replaced by the matching `cs2` knife models and data, keeping their saved numeric item IDs. There are no duplicate old knives in Creative/search when Unified is installed. CT/T knives use the pack's own close-range melee damage/range/cooldown and attack animation through the existing melee controller, without requiring the pack's internal ammunition token.

All 38 CS2 firearms, 12 knives and six attachments have Gun Smith Table recipes. Duplicate LR/TaCZ category recipes for the same knife/cost appear once. Unified lacks a recipe for its experimental AK and SG553 scope; the browser runtime supplies equivalent AK/AUG-scope material costs. Installed source files remain unmodified. Quartz, oak logs and gold nuggets map to their actual 1.7.10 items. Crafted USP-S/M4A1-S retain their recipe-fitted silencers. The table has Guns, Ammo, Attachments and Knives tabs, and the opt-in Recipes viewer uses the same material/crafting logic.

The integration uses the existing browser gun and melee systems; it does not execute arbitrary pack Lua scripts or PlayerAnimator clips. Script-specific animation variations and mode-specific behavior can therefore differ from the original modern mod. This is an adaptation, not an exact TaCZ/LR/CS2 execution port.

Hotbar switching: an outgoing pack model can remain selected by the native equip animation after its weapon controller has changed to the next slot. Those pixel-space models must never be rendered with the ordinary item's transform. The first-person renderer hides a pack model while its gun/knife view state does not match, and displays it again with its own camera transform when matched.
