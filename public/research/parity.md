# Minecraft Java 1.7.10 feature coverage

0.29.0 (WORLD-02f) builds streamed cells and columns in a Web Worker ahead of the player (same generator chain; worker results equal synchronous ones) and shifts streamed light incrementally, exactly equal to a fresh build; a chunk crossing still costs about 100 ms of relighting on the main thread. See [streaming](streaming.md).

0.28.0 adds Java population to the streaming preview (generation 13, WORLD-02e): per-area ores, trees, lakes, dungeons with loot, mineshafts, animals, spawners, mineshaft chest carts and snow from the seed, each column handing its chests/animals/spawners to the live world once and remembering that across reloads. Border-straddling features can differ from native in rare overlaps, each new area costs about a second of synchronous generation, and villages, strongholds and temples are still missing. Evidence is port regression plus a localhost walk; no new native probe. Generation-12 saves stay terrain-only. See [streaming evidence and limits](streaming.md).

0.27.0 adds an opt-in Java streaming terrain preview (generation 12): bounded resident columns, negative coordinates, moving light/mesh windows, indexed edits, paused unloaded work and IndexedDB world records. UI travel, return, reload, export/import and larger-save checks pass. Streamed population/structures, native tickets, per-chunk entity/storage ownership and incremental lighting remain open. Existing populated Java worlds retain v11. See [streaming evidence and limits](streaming.md).

0.26.0 adds empty-cart placement, boarding, forward-input rail travel, sneak dismount, F5 sitting and mounted browser save/import restoration. Chest carts can be crafted and placed; mineshaft chest carts remain containers. Thirty-eight new native vehicle records and the existing 34 chest-cart cases pass within their documented scopes; localhost loop, mineshaft, reload and export/import checks pass. Powered/detector/activator rails, mob pickup, other carts/boats and native chunk unloading remain open. See [minecarts](minecarts.md).

0.25.0 adds finite v11 Java population (ores, all ported biome decoration/trees/plants, lakes, dungeons, passive animals, ice/snow) with mineshafts first. Dungeon loot and supported animals become saved live state once. Twelve native 8×8 area replays across four seeds and all three world types pass; v9/v10 fingerprints stay unchanged. Light fixtures, missing structures/animal types and remaining content behaviors prevent a full parity claim. See [live population](population-live.md).

The target is the complete Java 1.7.10 feature set. **This build does not yet provide full parity.** “Implemented” below means a working browser implementation with the limitations stated; it does not mean original-client equivalence.

See the [accepted roadmap and execution tracker](parity-roadmap.md) and [original base-block catalogue](block-parity-catalogue.md). A registry mapping is not verification of behavior. Expanded audit catalogues cover [items and Creative subtypes](item-parity-catalogue.md), [block metadata](block-metadata-catalogue.md), [entity registrations](entity-parity-catalogue.md), [biome slots](biome-parity-catalogue.md), [default gamerules](gamerule-parity-catalogue.md), [crafting/smelting](recipe-parity-catalogue.md), [commands](command-parity-catalogue.md), [GUIs](gui-parity-catalogue.md) and [structures/generators](structure-parity-catalogue.md). Semantic variants and the remaining catalogue categories are still open.

## Systems not yet implemented or still incomplete

- Complete block and item registries, metadata variants, block shapes, fluids and block update rules.
- Full mob roster, original spawning, remaining animal interactions, bosses and advanced entity interactions (skeleton archers are in; see [bows](bows.md)). Pigs, cows, sheep, chickens and zombies run the original AI task lists with pathfinding; cows and sheep breed with wheat, chickens with seeds and pigs with carrots.
- Remaining crops/plant growth (sugar cane and cactus are in; see [plants](plants.md)), non-oak saplings and leaves, big oaks, fishing and animal-derived resources. Wheat, carrot and potato farming are implemented with the limits above.
- Enchanting in play (the enchantment registry, helper and table logic are ported standalone with 7,087 native records, not yet in the game; see [enchanting](enchanting.md)), brewing, potions and remaining status effects (mobs have only the four Hard spider spawn effects); difficulty rolls for mob equipment, children, jockeys and door breaking ([difficulty](difficulty.md)).
- Redstone in play (dust, torches, levers, buttons and lamps are ported standalone and headless with 21 native scenarios, not yet in the game; see [redstone](redstone.md)), repeaters/comparators, circuits, pistons, powered/detector/activator rails, remaining cart types, boats, mechanisms and storage containers such as trapped/ender chests, hoppers and dispensers.
- Native propagated-light population acceptance, structures beyond mineshafts and dungeons (mineshafts generate in new Java worlds since 0.24.0; see [structures](structures.md)), strongholds, villages, temples, dungeons, exact biome rendering, streamed infinite terrain, Nether and End. GEN-01..03 terrain/biomes/caves are playable in version-9 Java worlds; legacy snowy terrain remains available (see [generation](generation.md), [snow](snow.md)).
- Java multiplayer protocol/server compatibility, authentication, LAN play and server management.
- Java save compatibility (region areas up to 8×8 chunks convert to browser imports with a loss report; see [region import](region-import.md)), commands, gamerules, achievements/statistics, resource packs and mod support.
- Complete animation and rendering parity, remaining sound events, music, remaining menu and GUI behavior. Selected original media and recovered animation curves are now present; see [animation and audio](animations-and-sounds.md).
