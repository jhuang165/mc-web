# Native multi-chunk structure evidence

Generated by `tools/verify-structure-area.mjs` (probe `tools/probes/StructureAreaProbe.java`) into
`structure-area-reference.json`; replayed by `src/structure-area.test.js` through
`StructurePopulationArea` (size > 1).

## Method
The unchanged 1.7.10 `ChunkProviderGenerate` provides every chunk of an area first (terrain, caves,
ravines, then the four range-8 start searches: mineshaft, village, stronghold, scatteredFeature), then
populates x-outer / z-inner. Per populate step the probe records the ordered World call count/hash,
write count/hash, provider Random and World.rand `nextLong`; per chunk the final hash, tile entities
(chest, dispenser, furnace, spawner, flower pot) and entities (Villager, Witch, animals); plus carts,
pending ticks and drops.

## Coverage (9 areas, 224 populated chunks, 389,081 writes)
village120, village110 (6x6 plains villages), desertVillage126 (6x6), strongholdLibraryPortal9 and 11
(portal room + library), desertTemple120/17, jungleTemple671, swampHut579.

## Results
Eight areas replay exactly: call hashes, write hashes, both RNG streams, per-chunk hashes, tiles,
entities, carts, ticks and drops.

Fixed on the way: the desert temple 319-call gap was the TNT `onBlockAdded` power query (now ported,
with pressure plate 70 power); door neighbor logic, button break, dispenser/furnace facing, flower pot
tiles (`gen-world.js` createTile).

## Limits
- jungleTemple671: native chunk (0,14) (not a temple chunk) diverges in jungle-biome decoration
  (JS WorldGenFlowers reads y=35 where native continues tree-region calls near y=69; first 19,039
  ordered calls match). It reproduces with size 1, so it is not structure related. The test therefore
  checks only populate order, inputs, start maps and tile entities (not chunk 0,14), not step hashes,
  final hashes, entities, carts, ticks or drops for that area. Owner of decoration code should fix it.
- Redstone puzzle hooks (29, 55, 69, 93, 131, 132) are no-ops under `relaxRedstone` (jungle area only);
  the generic world still throws "unported" for them, so live jungle temples need an equivalent guard.
- Flower pot contents come from a meta table in `gen-world.js`; only meta 7 (red mushroom) is
  native-verified.
