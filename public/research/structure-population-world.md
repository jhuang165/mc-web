# Combined structure population world replay

This probe runs the unchanged Java 1.7.10 `ChunkProviderGenerate` provider with all four map features enabled, then calls its native population method on the generated chunk. It traces native search and population order, structure start maps, ordered calls and writes, tiles, entities, carts, pending ticks, drops, provider `Random`, `World.rand`, and the final chunk hash. The native fixture uses the same light service doubles as the earlier population probe (full block light and sky light 15); it does not model light propagation.

The recorded native run covers five one-chunk worlds. Seed 0 at `(-19,18)` exercises a mineshaft start; seed 17 at `(-25,5)` exercises a village start; seed 17 at `(-4,-55)` exercises a stronghold start; and seed 17 at `(10,-53)` exercises a scattered-feature temple start. The final fixture is an empty-map population baseline. Every row records the provider's `mineshaft → village → stronghold → scatteredFeature` search and population order. Native population reported 21,713 ordered world writes across these rows. The village fixture returns true from native village population, so the provider's lake suppression branch is selected; the subsequent native population trace shows its resulting call/write sequence.

`src/structure-population-area.test.js` replays all five fixtures through the standalone JavaScript area adapter. Input and final chunk hashes, all 21,713 ordered writes, both RNG streams, start maps, tiles/loot, entities, carts, pending ticks and drops match. The village result suppresses both lake paths. Initial input-hash comparisons were invalid because the recorder hashed the input after population; the probe now records it before population, and those terrain hashes match exactly.

Ordered world-call hashes also match for four fixtures. The desert temple fixture has 319 fewer recorded calls in JavaScript (70,951 versus native 71,270); its writes, final blocks, both RNG streams and other side effects still match. The missing call sources remain unresolved, and call-stream parity is not claimed for that fixture. This adapter remains separate from live generation versions and `population-world.js`; structure NBT persistence, exploration order, larger overlapping areas and propagated lighting remain open.
