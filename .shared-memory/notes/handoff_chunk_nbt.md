# WORLD-03c: chunk NBT storage adapter

Owner: codex-chunk-nbt. Standalone chunk/NBT work, no runtime/generator edits. Claim checks showed generation work complete and shared docs free, so separately claimed PROJECT.md/parity.md/parity-roadmap.md and added scoped WORLD-03a/b/c progress. App stays 0.23.4 / generation 9. No Site publication.

src/chunk-nbt.js implements chunkFromNbt/chunkToNbt around standalone Chunk storage and the raw/compressed NBT codecs. Preserves original-ID section bytes, optional Add, metadata/light, sky/no-sky, height/biome arrays, coordinates, flags and exact longs. Loaded counts match native recount; empty sections remain; duplicate Y uses last. LastUpdate is sidecar data, not lastSaveTime. InhabitedTime is Number when safe and BigInt otherwise; existing provider arithmetic will need explicit handling of exceptional longs before runtime integration. Opaque entity/tile/relative-tick Maps and unknown extension tags are copied and retained. No factories/scheduling/light propagation. Writer is pure, unlike native hasEntities reset. Shape validation is stricter than native malformed-input behavior.

ChunkNbtProbe.java and verify-chunk-nbt.mjs execute unchanged private AnvilChunkLoader payload writer/reader over real Chunk/ExtendedBlockStorage/NibbleArray and a constructor-free World stub (time, sky, pending records, recording schedule hook). Fourteen native fixtures cover all 16 sections, sparse/empty sections, invalid raw IDs/Add, negative/border coordinates, sky/no-sky, long endpoints/beyond 2^53, missing biome/optional fields, duplicate Y, absent/empty/nonempty ticks and native signed-delay wrap. Entity/tile lists are empty. JS fixtures independently match native written fields, load summaries and complete rewritten typed trees. Original loader reads/rewrites all 14 JS-generated payloads with identical storage, schedule calls and native raw bytes. No RegionFile or asynchronous save execution. Reference regeneration is byte-identical.

Seven new tests cover native evidence, gzip/zlib composition, opaque payload/unknown-field copying, raw invalid IDs/empty sections, no-sky and malformed shapes. Full npm test 760/760 on a5e5439, build OK, Python bridge 5/5. Separate headless Chrome temporary-profile smoke: 14 native loads + 28 gzip/zlib round trips; its 14 outputs also pass original loader/read/write validation. Ignored harness ../tools/research/chunk-nbt-browser.mjs.
