# travelperf6 (batch 36)

## Summary
- Resident sky check (goal 1). `RingLight.residentSees(cx, cz, qx, qy, qz, sky)` (headless-columns.js): resident chunks in the 3 x 3 no longer count as "may see the sky" with height-map minimum 0. Each resident column in the 29-cell box is asked whether its best sky cell (y = max(qy, height map), Manhattan distance d) can give more than the sky found (15 - d > sky); a path costs at least 1 per step, so false is exact. Uses the cached resident `heightAt`. Result identical to the plain search (3000 random cells beside the window with stone roofs placed in resident edge columns, both outcomes covered). Node benchmark on natural terrain: no measurable change (old and new 4.0-8.5 us/query vs plain 21-43 us, load 9-10; such cells are mostly opaque or already sky 15). So this is an exactness/bounds change, not a speed win I can show.
- Teleporter cache (goal 2). Native `destinationCoordinateCache` (bytecode-read; `dimensions.test.js` "Teleporter replay" already executes the original for first and second placement) reuses the cached portal on a repeat teleport to the same column, without a search and without checking the portal still exists; entries are swept every 100 ticks when unused for 600. The port made a new Teleporter per arrival, so repeat trips always searched again. `DimensionLive.exitCache` now keeps the cache per root and dimension (sweep by `host.ticks()`, a clock that went back drops it), `arrive` assigns it to the Teleporter and sets `world.time`, and the arrival prefetch uses the window round the cached portal. `savedPortalFor(columns, tt, cached)` and `ExitPrewarm.start(..., cached)` return the cached portal, so the prewarmed window matches the pick on repeat trips (`DimensionLive.cachedExit` supplies it). Behaviour change: a repeat trip within about 600 ticks goes to the cached portal even if it was broken (as natively). Not modelled: mob travel's own Teleporter cache; the clock is the page tick counter (loading screens do not advance it), not the destination world's time.
- Measurements (goal 3). Speculative cells 2 / 5 / 8 and prewarm workers 1 / 3 / 6 gave the same trip times within noise (0.52-0.67 s, 0 long tasks); load 7.4-10.3, above 8 for more than 10 minutes before. Caps unchanged. Details in loading-screens.md.
