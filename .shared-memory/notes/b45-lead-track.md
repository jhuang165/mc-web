# Batch 45 lead (claude, 2026-11-11)

Ten Sonnet tracks ran in `../wt45-<name>` on `batch45-<name>`. All were cut from 82874be6b (0.73.0, equal to github/main). The lead reviewed each one and merged it `--no-ff` on `batch45-lead`. Each track has its own note, `<name>-b45-track.md`. Every track was vanilla only, with no `server/` or `src/multiplayer/` edits. The gun side runs separately and was not touched.

## Merges (in merge order)
- **firefx2** (84eb8585f): a Creative fire punch-out plays a second fizz. javap shows that `ItemInWorldManager.onBlockClicked` (`mx.a(IIII)`) calls `World.extinguishFire` with a null player in both modes, so the client's own fizz and the server packet's both play. An item's lava fizz plays at posY. The re-audit is in `fire-fx.md`.
- **mobfixes** (385f9774e):
  - A piston-pushed mob lands before its step sound (`pushMove`).
  - The blaze strafe yaw uses the float pi.
  - New records: ocelot-sit `b45mf-*` (54 in the b44 set) and golem layout `fb43-golem-blaze-4517` (28 in fireballs-b43).
- **awayedge** (a7a69ddcc): away entities next to an uncopied loaded column are held, using the `EDGE` 8 bound chosen for the port. Falling blocks and the other non-mob entities tick in one join-ordered walk with the mobs.
- **entitylist3** (d686aafb1):
  - Explosions hit carts and boats; above 40 damage they break, and the drop joins the list.
  - Explosions push potions and golem balls.
  - Thrown balls hit hanging entities.
  - Cart and boat pushes run inside the mob's update.
  - `Boats.collide` uses a float sqrt.
  - `EntityListProbe` has 49 scenarios.
- **itematlas** (b881c0268, then lead fix 5002ca773): item sprites are cells of one Stitcher-laid-out atlas (`item-atlas.js`, `item-atlas-layout.js`). The materials apply `userData.st`. The cactus icon uses render type 13 quads.
  - Lead fix: `itemAtlasTexture` returns null when `document.createElement` is missing. Tests stub a partial document, and the mob-equipment, models and item-atlas tests failed without the guard.
- **modelfaces** (21ac459fc): `skinBox` swaps the bottom-face rows (`ModelFacesProbe`). Third-person held poses come from `HeldPoseProbe`: the rod and carrot-on-a-stick turn, and a cast rod is drawn as a stick. The chest bottom override is gone because `skinBox` now covers it.
- **horses** (0c65ea6da):
  - 88 records in `enderman-wolf-b45-reference.json` (food, love, breeding, foal health and growth, the 1.4 x 1.6 float box).
  - **Conflict** in `tools/verify-endermanwolf.mjs`: the mobfixes and horses record-count assertions. Resolved to one chain: b45 88, b44 54, b43 17, else 55. The b44 and b45 references were regenerated byte-identical.
- **clienthits** (8cc975c8a, then lead fix 710c075f7): client arrows, hooks and thrown entities hit client copies (`TrackerHitsProbe`, 19 scenarios).
  - Lead fix: the track played the client copies' sounds through `objectTracker.hooks.sound`. javap shows `RenderGlobal.playSound` (`bma.a(String,DDDFF)V`) is a bare return and `WorldClient` does not override it, so those sounds are silent in 1.7.10. The hook was removed; the sounds are still logged. The comments and the track note were corrected.
- **dragonclient** (fca09f94c, then lead fix c0d9e7fe5): the dragon's client parts, health, death branch and fx (`MobTracker.takeFx`), and squid air in S1C. `tracker-mounts-reference.json` has 14 cases.
  - Lead fix: the track made a ridden pig's client copy packet-driven. The port's camera and seat still follow the live pig, so the drawn pig would lag behind its rider. `followLive` is restored for ridden mounts until the seat moves to the client copy, and the test asserts it. The trade-off is listed in remaining-gaps.
- **creeperwitch** (7e34f1de5): 77 records. The creeper explosion runs inside its update, the blast push uses the 1.62F eye height, a dead witch still rolls its drinks, and a thrown potion makes three gaussians before the aim.
  - Its probe set first used `EW_SET=b45` and the same reference file as horses. It was sent back, merged the lead, and renamed the set `b45cw` (`enderman-wolf-b45cw-reference.json`). XP orb velocities were left out of that reference because they come from Math.random.

## Lead fix (flake)
- `src/away-mobs.test.js`, "roofed pit": the full suite failed once on the zombie's away wander. It also fails 2/100 on 0.73.0, so it predates this batch. The runs now use a seeded Math.random stub, LCG 4501, restored in `finally`. The file passed 15/15. This commit (460bc11b6) also holds the batch 45 `remaining-gaps.md` update.

## Verification (batch45-lead before the release commit)
- `npm test`, once after all ten merges: 5935 tests, 5934 passed, 1 failed. The failure was the flake above, which was then fixed and its file re-run. The suite was not re-run, per the one-run rule.
- Targeted runs on the merges: away and entity-list 312/312; horse and mobs 529/529; object tracker 153/153; tracker-mounts and neighbours 178/178 and 20/20.
- `npm run build`: ok (5.2 s). Bridge unittest: OK. `git diff --check 82874be6b`: clean.
- Muted headless Chrome smoke (vite :5545, `--mute-audio`, master volume 0; output in `artifacts/b45-lead/`; script `smoke.mjs`):
  - Creative world, loaded in 2.0 s, with no long tasks after load. 160 ticks per 8 s in the Overworld and the Nether.
  - On a stone platform at y 150:
    - Three item frames (diamond, stick, compass) and five dropped sprites (diamond, coal, stick, golden apple, sword).
    - The held diamond and sword in first person, and the third-person view.
    - The hotbar and the creative inventory.
  - Every sprite draws its own cell, with no bleed. The same script against wt44-lead (0.73.0, :5546, `artifacts/b45-base/`) gives the same frames and items, apart from random drop scatter and the compass needle.
  - The only console errors were the known static 404 and the localStorage message from the final about:blank page. Both are the same on the base.
  - Smoke-script pitfalls: `items.spawn` takes port ids, not original ids (264 is a stone-like block in the port), so the script reads the ids from `/give` stacks. A new world needs Creative, or cheats, for commands.
