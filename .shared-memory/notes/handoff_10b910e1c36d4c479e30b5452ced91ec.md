Java region import now converts Pig, Cow, MushroomCow, Sheep, Chicken, Wolf, Spider, CaveSpider, Creeper, Witch, Silverfish and SnowMan (commit d917ae6, pushed to github main).

How it works:
- java-mobs.js adds JAVA_SUMMON_MOBS and importedMobType. These ids go through summonedMobRecord.
- HealF is clamped to the saved Attributes generic.maxHealth, because EntityLivingBase reads Attributes first.
- Fire, CustomName, PersistenceRequired and gear are kept.

Evidence:
- tools/probes/MobNbtProbe.java writes the native mobs and tools/verify-mob-nbt.mjs saves the output to public/research/mob-nbt-reference.json (22 records).
- The unchanged classes write with sa.c(dh) and read back with sg.a(dh, ahb).

Export fixes in region-export.js:
- Creeper: powered (only when charged), Fuse 30, ExplosionRadius 3 and ignited.
- Chicken: IsChickenJockey 0.
- Skeleton: SkeletonType is always written; checked against the yl bytecode.
- Age/InLove are no longer written for skeleton, creeper, spider, cave spider, witch, silverfish or snow golem.

Tests:
- src/mob-nbt.test.js checks each native record's getters, the live EntityWorld restore, a 22-mob region import and the export→import round trip.
- npm test: 3117/3117 pass. npm run build passes. No browser check, since this is a file-import path.

Open:
- Riders are still lost.
- There are no chicken jockeys.
- Live creepers ignore a saved Fuse/ExplosionRadius.
- Witch equipment beyond the held item is ignored.
- Other entity ids (e.g. EntityHorse variants are covered; minecarts, boats, paintings and item frames are not) are still counted as lost.
