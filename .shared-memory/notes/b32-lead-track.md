## Merges
- **interchange9**: `TileTicksProbe` runs the unchanged `WorldServer.tickUpdates` (6 new scenarios, 30 total): at most 1000 entries leave the tree per call in time, priority, creation order. Falling blocks are capped at 1000 too. `ForeignTicks` ages foreign entries in the live world and runs any whose block the port ticks. Fluid, fire and falling priorities are stored (`p`, only when not 0). Horse chest stacks with an unmapped `Damage` keep it as `rawDamage`.
- **awaymobs**: the away run ticks mobs (no player: `ai.player.absent`, despawnEntity does nothing, bytecode-read), arrows, thrown projectiles and potions, rockets, fireballs, hanging entities, and spawner and hopper carts for the first 1200 ticks. Dispensers shoot every projectile there. Live fix: `redstone-runtime.js` never forwarded fireball and firework dispenses to the host.
- **serverdist2**: every aimed entity (mob, cart, boat, painting, frame) goes through C02 with the native sight ray from feet + 1.62 and the attack kick on items, arrows, orbs and self. The batch 31 gate read `aimedEntity.x` (NaN) and refused every mob click; fixed. The dedicated server edit path applies C07/C08 and sends the refusal as chat. Fallen buttons (77, 143) and powered TNT run in population callbacks (262 native records, `neighbor-chains-reference.json`).
- **walkperf2**: ring-light `search` shortcuts (same answers, tested against the plain search), faster `relightSteps` (same light and box, tested; a shift about 21 -> 14 ms), and the Teleporter exit's cells fetched in spare lanes before the Teleporter runs (second fetch 0 ms). Worker cap kept at 3.
- **villagefight4**: 22 new native records (steps, terrace, pool, closed and open doors, arrows into stone, fence, glass and slab, Hard reinforcements in a dark world); all 48 replay exactly. Fixes: fdlibm `StrictMath.log` in `nextGaussian`, skeleton damage float grouping, `canSee` by `rayTraceBlocks`, long-memory attack without sight, path start from the box edge, the splash inside the move, mobs created mid-pass tick in that pass. Arrow headings are now derived from seeded Randoms. The silverfish test seeds eight fixed starts (about 2 in 40000 random starts wandered past 300 ticks).
- **Conflicts**: none. `main.js` auto-merged (awaymobs, serverdist2), as did `ai.js` (awaymobs, villagefight4) and `dimension-live.js` (awaymobs, walkperf2).
- **Lead fix (eb498c6c9)**: `ForeignTicks.tick` used `Math.min(...entries)`, which throws on a list over the spread-argument limit; now a loop, with a 300000-entry test.
