0.12.0 adds 1.7.10 entity shadows, committed as 31b2918 and pushed to github/main. The Site is not published.

Changed:
- `src/shadows.js` ports Render.doRenderShadowAndFire / renderShadow / func_147907_a (bno) as drawn with Fancy graphics:
  - shadow sizes: items and XP orbs 0.15 at 0.75 opacity; pig and cow 0.7; zombie 0.5; children half size;
  - fades: (1 − d²/256) by distance from the viewer's eye, then (opacity − (centreY − cellY)/2) × 0.5 × brightness[light];
  - only cells with light above 3 draw, and only on renderAsNormalBlock blocks;
  - quads sit 1/64 above the block top, using clamped misc/shadow.png.
- ShadowRenderer draws one batched blended mesh with no depth writes, fogged, with renderOrder −1 so it draws before water.
- `src/scene.js`: setShadows(casters, viewer). `src/main.js`: shadowCasters() for items (interpolated, posY = box bottom + 0.125), orbs and mobs. `src/light-material.js` now exports FOG_PARS. I added light-material.js to this claim.
- `tools/probes/ShadowProbe.java` and `tools/verify-shadows.mjs` write `public/research/shadow-reference.json`: material, renderAsNormalBlock and bounds for every game block's 1.7.10 counterpart. Glass, water, torch, farmland, wheat, tall grass and chest take no shadow.
- Docs: `public/research/shadows.md`, a parity.md row, PROJECT.md, and the notes modal link.

Tests:
- npm test: 97/97 pass (6 new shadow tests).
- npm run build: clean.
- Browser preview:
  - soft shadows show under a dropped block and a pig;
  - the pig's shadow stops at the water's edge;
  - a cow in a dark cave correctly casts none;
  - no console errors.
