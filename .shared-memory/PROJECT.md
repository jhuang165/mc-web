Live Site: https://blockworld-mc-web-1030.jhuang165.chatgpt.site (owner-private).
GitHub: https://github.com/jhuang165/mc-web . Canonical checkout in this Desktop workspace: `mc-web/game`.

Working: finite seeded terrain, movement, Creative/Survival, hunger/health, shaped crafting and furnace, original textures/audio, first-person animation, pigs/cows/zombies, wheat farming and cow breeding, XP, classic menus. 0.6 corrects native crafting/count coordinates and integer GUI scaling; mining uses original tool behavior, Java float rounding, water/air penalties and wear. Dev builds expose `window.__mc` for browser checks.

Remaining: creative tab GUI, item entity physics, void fog/weather/entity shadows, trapped/ender chests and other storage containers, complete original registries/mobs, armor rendering, enchanting/anvils, status effects, redstone, structures, weather, dimensions, Java terrain/seeds/saves, multiplayer and remaining rendering details. Workflow: read context, claim distinct paths, implement, test, leave notes, commit reviewed changes, push GitHub. GitHub pushing and Sites publication are separate.
